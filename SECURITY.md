# Security Policy

## Scope and intended use

LAN Scan is a defensive, home-network utility. It discovers hosts on a network
**you own or are authorized to scan** by making ordinary TCP connections and
reading the local ARP cache. It requires no elevated privileges, sends no data
off the machine, and includes no exploitation capability. Only scan networks you
control.

## Reporting a vulnerability

If you find a security issue in LAN Scan itself, please do not open a public
issue. Email **bheng.code@gmail.com** with:

- a description of the issue and its impact,
- steps to reproduce, and
- any suggested fix.

You can expect an acknowledgement within a few days.

## Supported versions

The latest release on the `main` branch receives security fixes.
